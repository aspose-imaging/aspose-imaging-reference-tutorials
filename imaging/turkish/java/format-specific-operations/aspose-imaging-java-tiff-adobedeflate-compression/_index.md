### Java'da TIFF görüntülerine deflate sıkıştırması nasıl uygulanır?

Kaynak görüntünüzü yükleyin, `TiffOptions`'ı `CompressionType.AdobeDeflate` ile yapılandırın ve sonucu kaydedin. Bu üç adımlı desen, tüm dönüşümü tek bir bellek‑verimli akışta yönetir. try‑with‑resources bloğu kullanarak, yerel kaynakların otomatik olarak serbest bırakılmasını sağlarsınız; bu, büyük görüntüler veya dosya partileri işlenirken özellikle önemlidir.

`RasterImage` sınıfı, Aspose.Imaging'in bellek içinde herhangi bir raster‑tabanlı resmi (PNG, JPEG, BMP, vb.) temsil eden temel nesnesidir. Yükledikten sonra pikselleri manipüle edebilir, çözünürlüğü değiştirebilir veya sadece görüntüyü yeniden kodlayabilirsiniz.

`TiffOptions` sınıfı, bir TIFF dosyasının nasıl yazılacağını belirleyen ayarları tanımlar; örneğin sıkıştırma, çözünürlük ve renk modu. `Compression = CompressionType.AdobeDeflate` ayarı deflate algoritmasını etkinleştirir.

`TiffFrame` sınıfı, bir TIFF dosyasındaki tek bir sayfa veya katmanı temsil eder. `save` çağırdığınızda, Aspose.Imaging sağladığınız seçenekleri kullanarak çerçeveyi yazar.

### Görüntüyü RasterImage Olarak Yükleme

```java
try (RasterImage image = (RasterImage) Image.load("YOUR_DOCUMENT_DIRECTORY/SampleTiff1.tiff")) {
    // Additional code will go here
}
```  
*Açıklama:* `Image.load` yöntemi, dosyayı bir try‑with‑resources bloğu içinde bir `RasterImage` örneğine okur ve yerel kaynakların otomatik olarak serbest bırakılmasını garanti eder.

### TIFF seçeneklerini yapılandırma

```java
TiffOptions options = new TiffOptions(TiffExpectedFormat.Default);
options.setBitsPerSample(new int[] { 8, 8, 8 });
options.setPhotometric(TiffPhotometrics.Rgb);
options.setXresolution(new TiffRational(72));
options.setYresolution(new TiffRational(72));
options.setResolutionUnit(TiffResolutionUnit.Inch);
options.setPlanarConfiguration(TiffPlanarConfig.Contiguous);
options.setCompression(TiffCompression.AdobeDeflate);
```  
*Açıklama:* `TiffOptions` yapılandırılarak AdobeDeflate sıkıştırması belirtilir, istenen çözünürlük (ör. baskı için 300 DPI) ayarlanır ve uygun renk modu seçilir.

### Dönüştürülmüş görüntüyü kaydetme

```java
try (TiffFrame tiffFrame = TiffFrame.fromRasterImage(image)) {
    TiffImage tiffImage = new TiffImage(tiffFrame);
    tiffImage.save("YOUR_OUTPUT_DIRECTORY/SavingRasterImage_out.tiff", options);
}
```  
*Açıklama:* `TiffFrame` raster veriyi sarar ve `save` daha önce tanımlanan seçenekleri kullanarak son TIFF dosyasını yazar. try‑with‑resources deseni dosya tutamacının doğru şekilde kapatılmasını sağlar.
