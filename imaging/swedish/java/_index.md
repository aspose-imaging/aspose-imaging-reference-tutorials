## Hur skapar jag en animerad GIF i Java med Aspose.Imaging?
`GifImage` är Aspose.Imaging‑klassen som representerar en animerad GIF och tillhandahåller metoder för att lägga till ramar, sätta fördröjning och kontrollera loopning.  
Läs in en basbild, skapa ett `GifImage`‑objekt, lägg till varje ram, sätt per‑ram‑fördröjning och spara med filändelsen `.gif`. Detta hela arbetsflöde kan slutföras på under 20 rader kod och körs på mindre än 200 ms för en 10‑ramars, 800 × 600 pixel animation på en typisk server.

`GifImage`‑klassen representerar en animerad GIF‑bild i Aspose.Imaging. Den tillhandahåller metoder som `addFrame()`, `setDelay()` och `setLoopCount()` för att kontrollera animationens uppspelning.

## Hur konverterar jag en bild i Java med Aspose.Imaging?
`Image.load()` är en statisk metod som laddar en bildfil till ett Aspose.Imaging Image‑objekt för vidare bearbetning.  
Anropa den statiska `Image.load()`‑metoden för att läsa källfilen, och anropa sedan `save()` med önskat utdataformat. Biblioteket bevarar automatiskt EXIF‑metadata, färgprofiler och utför förlustfri konvertering när målformatet stödjer det.

## Så konverterar du en bild i Java med Aspose.Imaging
Att konvertera mellan bildformat är en vanlig uppgift. Med Aspose.Imaging laddar du helt enkelt en bild, anger önskat utdataformat och sparar. Biblioteket bevarar metadata, hanterar färgprofiler och tillämpar automatiska kvalitetsoptimeringar.

```java
// Create an animated GIF using Aspose.Imaging for Java
import com.aspose.imaging.*;
import com.aspose.imaging.imageoptions.*;

public class CreateAnimatedGif {
    public static void main(String[] args) throws Exception {
        // Load source images
        String[] frames = {"frame1.png", "frame2.png", "frame3.png"};
        try (GifImage gif = (GifImage) new Image(frames[0])) {
            // Add remaining frames
            for (int i = 1; i < frames.length; i++) {
                gif.addFrame(new Image(frames[i]));
            }
            // Set animation properties
            gif.setLoopCount(0); // infinite loop
            // Save animated GIF
            gif.save("animated.gif", new GifOptions());
        }
    }
}
```
