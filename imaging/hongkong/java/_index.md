## 如何在 Java 中使用 Aspose.Imaging 建立動畫 GIF？

`GifImage` 是 Aspose.Imaging 中代表動畫 GIF 的類別，提供加入影格、設定延遲與控制迴圈的功能。  
載入基礎圖像，實例化 `GifImage` 物件，逐一加入影格、設定每個影格的延遲，最後以 `.gif` 副檔名儲存。整個工作流程可在 20 行程式碼以內完成，於一般伺服器上處理 10 影格、800 × 600 像素的動畫，執行時間少於 200 毫秒。

`GifImage` 類別在 Aspose.Imaging 中代表動畫 GIF 圖像，提供 `addFrame()`、`setDelay()`、`setLoopCount()` 等方法以控制動畫播放。

## 如何在 Java 中使用 Aspose.Imaging 轉換圖像？

`Image.load()` 是一個靜態方法，可將圖像檔載入為 Aspose.Imaging 的 Image 物件以供後續處理。  
呼叫靜態的 `Image.load()` 方法讀取來源檔案，然後以所需的輸出格式呼叫 `save()`。當目標格式支援時，函式庫會自動保留 EXIF 中繼資料、色彩描述檔，並執行無損轉換。

## 如何使用 Aspose.Imaging 轉換 java 圖像

在圖像格式之間轉換是常見的工作。使用 Aspose.Imaging 時，只需載入圖像、設定所需的輸出格式，然後儲存。函式庫會保留中繼資料、處理色彩描述檔，並套用自動品質最佳化。

```java
// Create an animated GIF using Aspose.Imaging for Java
import com.aspose.imaging.*;
import com.aspose.imaging.imageoptions.*;

public class CreateAnimatedGif {
    public static void main(String[] args) throws Exception {
        // Load source images
        String[] frames = {"frame1.png", "frame2.png", "frame3.png"};
        try (GifImage gif = (GifImage) new Image(frames[0])) {
            // Add remaining frames
            for (int i = 1; i < frames.length; i++) {
                gif.addFrame(new Image(frames[i]));
            }
            // Set animation properties
            gif.setLoopCount(0); // infinite loop
            // Save animated GIF
            gif.save("animated.gif", new GifOptions());
        }
    }
}
```
