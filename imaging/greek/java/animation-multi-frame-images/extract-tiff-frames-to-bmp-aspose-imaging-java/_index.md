## Πώς να μετατρέψετε tiff σε bmp χρησιμοποιώντας το Aspose.Imaging Java;

`Image.load` είναι μια στατική μέθοδος που διαβάζει ένα αρχείο εικόνας και επιστρέφει ένα αντικείμενο `Image` που αντιπροσωπεύει την φορτωμένη εικόνα.

Φορτώστε το πολυ‑σελίδες TIFF με `Image.load("source.tif")`, η οποία διαβάζει το αρχείο και επιστρέφει ένα αντικείμενο `Image` που αντιπροσωπεύει το έγγραφο. Στη συνέχεια, καλέστε `save` σε κάθε πλαίσιο χρησιμοποιώντας μια παρουσία `BmpOptions`. Αυτό το σύντομο μοτίβο εξάγει κάθε σελίδα και την γράφει ως ξεχωριστό αρχείο BMP, διαχειριζόμενο αυτόματα το βάθος χρώματος και τη συμπίεση.

Παρακάτω περπατάμε μέσα από τα τρία βασικά βήματα, το καθένα εικονογραφημένο με ένα σύντομο απόσπασμα κώδικα.

### Βήμα 1: φόρτωση της εικόνας TIFF
```java
try (TiffImage multiImage = (TiffImage) Image.load("YOUR_DOCUMENT_DIRECTORY/sample.tiff")) {
    // Proceed to process each frame.
}
```  

### Βήμα 2: επανάληψη πάνω στα πλαίσια TIFF
```java
int frameCounter = 0;
for (TiffFrame tiffFrame : multiImage.getFrames()) {
    // Process each frame.
}
```  

### Βήμα 3: εξαγωγή και αποθήκευση κάθε πλαισίου ως BMP
`BmpOptions` ορίζει τη μορφή εξόδου και τις επιλογές κωδικοποίησης για αρχεία BMP.

```java
multiImage.setActiveFrame(tiffFrame);
Color[] pixels = multiImage.loadPixels(tiffFrame.getBounds());

try (BmpOptions bmpCreateOptions = new BmpOptions()) {
    bmpCreateOptions.setBitsPerPixel(24);
    String outputPath = String.format("%sConcatExtractTIFFFramesToBMP_out%d.bmp", "YOUR_OUTPUT_DIRECTORY/", frameCounter);

    bmpCreateOptions.setSource(new FileCreateSource(outputPath, false));
    try (BmpImage bmpImage = (BmpImage) Image.create(bmpCreateOptions, tiffFrame.getWidth(), tiffFrame.getHeight())) {
        bmpImage.savePixels(tiffFrame.getBounds(), pixels);
        bmpImage.save(outputPath);  // Save the BMP file.
    }
}
frameCounter++;
```
