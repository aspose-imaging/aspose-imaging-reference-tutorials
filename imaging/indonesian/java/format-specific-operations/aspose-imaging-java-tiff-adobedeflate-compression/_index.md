### Cara menerapkan kompresi deflate pada gambar TIFF di Java?

Muat gambar sumber Anda, konfigurasikan `TiffOptions` dengan `CompressionType.AdobeDeflate`, dan simpan hasilnya. Pola tiga langkah ini menangani seluruh konversi dalam alur tunggal yang efisien memori. Dengan menggunakan blok try‑with‑resources, Anda memastikan sumber daya native dilepaskan secara otomatis, yang sangat penting saat memproses gambar atau batch file berukuran besar.

Kelas `RasterImage` adalah objek inti Aspose.Imaging yang mewakili gambar berbasis raster apa pun (PNG, JPEG, BMP, dll.) dalam memori. Setelah dimuat, Anda dapat memanipulasi piksel, mengubah resolusi, atau sekadar meng‑encode ulang gambar.

Kelas `TiffOptions` mendefinisikan pengaturan cara file TIFF ditulis, seperti kompresi, resolusi, dan mode warna. Menetapkan `Compression = CompressionType.AdobeDeflate` mengaktifkan algoritma deflate.

Kelas `TiffFrame` mewakili satu halaman atau lapisan dalam file TIFF. Saat Anda memanggil `save`, Aspose.Imaging menulis frame menggunakan opsi yang Anda berikan.

### Memuat gambar sebagai RasterImage

```java
try (RasterImage image = (RasterImage) Image.load("YOUR_DOCUMENT_DIRECTORY/SampleTiff1.tiff")) {
    // Additional code will go here
}
```  
*Penjelasan:* Metode `Image.load` membaca file ke dalam instance `RasterImage` di dalam blok try‑with‑resources, menjamin bahwa sumber daya native dilepaskan secara otomatis.

### Mengonfigurasi opsi TIFF

```java
TiffOptions options = new TiffOptions(TiffExpectedFormat.Default);
options.setBitsPerSample(new int[] { 8, 8, 8 });
options.setPhotometric(TiffPhotometrics.Rgb);
options.setXresolution(new TiffRational(72));
options.setYresolution(new TiffRational(72));
options.setResolutionUnit(TiffResolutionUnit.Inch);
options.setPlanarConfiguration(TiffPlanarConfig.Contiguous);
options.setCompression(TiffCompression.AdobeDeflate);
```  
*Penjelasan:* Dengan mengonfigurasi `TiffOptions`, Anda menentukan kompresi AdobeDeflate, menetapkan resolusi yang diinginkan (misalnya 300 DPI untuk cetak), dan memilih mode warna yang tepat.

### Menyimpan gambar yang dikonversi

```java
try (TiffFrame tiffFrame = TiffFrame.fromRasterImage(image)) {
    TiffImage tiffImage = new TiffImage(tiffFrame);
    tiffImage.save("YOUR_OUTPUT_DIRECTORY/SavingRasterImage_out.tiff", options);
}
```  
*Penjelasan:* `TiffFrame` membungkus data raster, dan `save` menulis file TIFF akhir menggunakan opsi yang telah didefinisikan sebelumnya. Pola try‑with‑resources memastikan handle file ditutup dengan benar.
