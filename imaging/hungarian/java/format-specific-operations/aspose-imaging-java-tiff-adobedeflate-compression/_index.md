### Hogyan alkalmazzuk a deflate tömörítést TIFF képeken Java‑ban?

Töltsd be a forrásképet, konfiguráld a `TiffOptions`‑t a `CompressionType.AdobeDeflate`‑val, majd mentsd el az eredményt. Ez a háromlépéses minta egyetlen, memóriahatékony folyamatban kezeli a teljes konverziót. A try‑with‑resources blokk használatával automatikusan felszabadulnak a natív erőforrások, ami különösen fontos nagy képek vagy fájlköteg feldolgozásakor.

A `RasterImage` osztály az Aspose.Imaging központi objektuma, amely bármely raszteres képet (PNG, JPEG, BMP stb.) memóriában képvisel. Betöltés után manipulálhatod a pixeleket, módosíthatod a felbontást, vagy egyszerűen újrakódolhatod a képet.

A `TiffOptions` osztály határozza meg a TIFF fájl írásának beállításait, például a tömörítést, felbontást és színmódot. A `Compression = CompressionType.AdobeDeflate` beállítás aktiválja a deflate algoritmust.

A `TiffFrame` osztály egyetlen oldalt vagy réteget képvisel egy TIFF fájlban. Amikor a `save` metódust meghívod, az Aspose.Imaging a megadott beállításokkal írja ki a keretet.

### Kép betöltése RasterImage‑ként

```java
try (RasterImage image = (RasterImage) Image.load("YOUR_DOCUMENT_DIRECTORY/SampleTiff1.tiff")) {
    // Additional code will go here
}
```  
*Magyarázat:* Az `Image.load` metódus beolvassa a fájlt egy `RasterImage` példányba egy try‑with‑resources blokkban, biztosítva, hogy a natív erőforrások automatikusan felszabaduljanak.

### TIFF beállítások konfigurálása

```java
TiffOptions options = new TiffOptions(TiffExpectedFormat.Default);
options.setBitsPerSample(new int[] { 8, 8, 8 });
options.setPhotometric(TiffPhotometrics.Rgb);
options.setXresolution(new TiffRational(72));
options.setYresolution(new TiffRational(72));
options.setResolutionUnit(TiffResolutionUnit.Inch);
options.setPlanarConfiguration(TiffPlanarConfig.Contiguous);
options.setCompression(TiffCompression.AdobeDeflate);
```  
*Magyarázat:* A `TiffOptions` konfigurálásával megadod az AdobeDeflate tömörítést, beállítod a kívánt felbontást (pl. 300 DPI nyomtatáshoz), és kiválasztod a megfelelő színmódot.

### A konvertált kép mentése

```java
try (TiffFrame tiffFrame = TiffFrame.fromRasterImage(image)) {
    TiffImage tiffImage = new TiffImage(tiffFrame);
    tiffImage.save("YOUR_OUTPUT_DIRECTORY/SavingRasterImage_out.tiff", options);
}
```  
*Magyarázat:* A `TiffFrame` becsomagolja a raszteres adatokat, a `save` pedig a korábban definiált beállításokkal írja ki a végleges TIFF fájlt. A try‑with‑resources minta biztosítja, hogy a fájlkezelő helyesen záródjon.
