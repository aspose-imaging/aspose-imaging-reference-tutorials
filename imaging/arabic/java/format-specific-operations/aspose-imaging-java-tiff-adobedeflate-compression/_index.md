### كيفية تطبيق ضغط deflate على صور TIFF في Java؟
حمّل صورة المصدر، قم بتكوين `TiffOptions` باستخدام `CompressionType.AdobeDeflate`، واحفظ النتيجة. هذا النمط المكوّن من ثلاث خطوات يتعامل مع التحويل بالكامل في تدفق واحد فعال للذاكرة. باستخدام كتلة try‑with‑resources، تضمن تحرير الموارد الأصلية تلقائيًا، وهو أمر مهم بشكل خاص عند معالجة صور كبيرة أو دفعات من الملفات.

فئة `RasterImage` هي الكائن الأساسي في Aspose.Imaging الذي يمثل أي صورة نقطية (PNG، JPEG، BMP، إلخ) في الذاكرة. بعد التحميل، يمكنك تعديل البكسلات، تغيير الدقة، أو ببساطة إعادة ترميز الصورة.

فئة `TiffOptions` تحدد الإعدادات لكيفية كتابة ملف TIFF، مثل الضغط، الدقة، ووضع اللون. تعيين `Compression = CompressionType.AdobeDeflate` يفعّل خوارزمية deflate.

فئة `TiffFrame` تمثل صفحة أو طبقة واحدة داخل ملف TIFF. عند استدعاء `save`، يقوم Aspose.Imaging بكتابة الإطار باستخدام الخيارات التي قدمتها.

### تحميل صورة كـ RasterImage
```java
try (RasterImage image = (RasterImage) Image.load("YOUR_DOCUMENT_DIRECTORY/SampleTiff1.tiff")) {
    // Additional code will go here
}
```  
*شرح:* طريقة `Image.load` تقرأ الملف إلى كائن `RasterImage` داخل كتلة try‑with‑resources، مما يضمن تحرير الموارد الأصلية تلقائيًا.

### تكوين خيارات TIFF
```java
TiffOptions options = new TiffOptions(TiffExpectedFormat.Default);
options.setBitsPerSample(new int[] { 8, 8, 8 });
options.setPhotometric(TiffPhotometrics.Rgb);
options.setXresolution(new TiffRational(72));
options.setYresolution(new TiffRational(72));
options.setResolutionUnit(TiffResolutionUnit.Inch);
options.setPlanarConfiguration(TiffPlanarConfig.Contiguous);
options.setCompression(TiffCompression.AdobeDeflate);
```  
*شرح:* من خلال تكوين `TiffOptions`، تحدد ضغط AdobeDeflate، وتضبط الدقة المطلوبة (مثلاً 300 DPI للطباعة)، وتختار وضع اللون المناسب.

### حفظ الصورة المحوّلة
```java
try (TiffFrame tiffFrame = TiffFrame.fromRasterImage(image)) {
    TiffImage tiffImage = new TiffImage(tiffFrame);
    tiffImage.save("YOUR_OUTPUT_DIRECTORY/SavingRasterImage_out.tiff", options);
}
```  
*شرح:* `TiffFrame` يلف البيانات النقطية، و`save` يكتب ملف TIFF النهائي باستخدام الخيارات المعرفة مسبقًا. نمط try‑with‑resources يضمن إغلاق مقبض الملف بشكل صحيح.
