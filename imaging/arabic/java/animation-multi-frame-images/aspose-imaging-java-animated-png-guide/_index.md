# إنشاء PNG متحرك في Java باستخدام ترخيص Aspose Imaging

## مقدمة

إذا كنت بحاجة إلى **إنشاء PNG متحرك في Java** وتريد حلاً موثوقًا وجاهزًا للإنتاج، فإن **ترخيص Aspose Imaging** يمنحك الوصول الكامل إلى API عالية الأداء للمكتبة. سواء كنت تبني بوابة ويب، أو واجهة سطح مكتب، أو لوحة معلومات لتصوير البيانات، فإن PNG المتحرك (APNG) يضيف حركة سلسة دون عيوب GIFs. يوضح هذا الدليل كيفية إضافة تبعية Maven، تحويل ملف TIFF متعدد الصفحات إلى APNG، والتحكم في توقيت الإطارات، حتى تتمكن من تقديم رسوم متحركة مصقولة بسرعة.

## إجابات سريعة
- **ما المكتبة التي تمكّن إنشاء APNG في Java؟** Aspose.Imaging مع تبعية Aspose Imaging Maven.  
- **ما الصيغة التي يمكن تحويلها إلى APNG؟** يمكن تحويل ملفات TIFF متعددة الصفحات إلى PNG متحرك.

- **هل يمكنني استخدام Maven أو Gradle؟** كلاهما مدعومان؛ فقط أضف التبعية المناسبة.

ترخيص **Aspose Imaging** هو ملف يفتح مجموعة الميزات الكاملة غير المقيدة لمكتبة Aspose.Imaging for Java، ويزيل علامات مائية التقييم وحدود الاستخدام. تقوم بتحميل الترخيص مرة واحدة عند بدء تشغيل التطبيق، وتعمل جميع استدعاءات API اللاحقة دون قيود تجريبية.

## كيفية تحويل TIFF إلى APNG باستخدام Aspose.Imaging؟

حمّل ملف TIFF المصدر، اضبط خيارات APNG، واحفظ النتيجة. تستخرج المكتبة كل صفحة من TIFF كإطار منفصل وتكتب PNG متحرك متوافق مع المعايير. يتيح لك هذا أيضًا ضبط توقيت الإطار الافتراضي، اختيار مستوى الضغط، وإعادة تحجيم الإطارات قبل الحفظ، مما يمنحك تحكمًا كاملاً في جودة الرسوم المتحركة النهائية وحجم الملف.

### تحميل صورة

`Image` هو الفئة الأساسية التي تمثل كائن صورة في Aspose.Imaging.

```java
import com.aspose.imaging.Image;
```

```java
String inputFilePath = "YOUR_DOCUMENT_DIRECTORY/img4.tif";

try (Image image = Image.load(inputFilePath)) {
    // The image is now loaded and ready for manipulation.
}
```

### ضبط مدة الإطار الافتراضية لـ APNG

`ApngOptions` يضبط الإعدادات لحفظ صورة كـ PNG متحرك.

```java
import com.aspose.imaging.imageoptions.ApngOptions;
```

```java
ApngOptions op = new ApngOptions();
op.setDefaultFrameTime(500); // Default frame time set to 500 milliseconds
```

### حفظ الصورة كـ APNG

جهّز مسار الإخراج واستدعِ `save` مع الخيارات المكوّنة:

```java
String outputFilePath = "YOUR_OUTPUT_DIRECTORY/img4.tif.500ms.png";
```

```java
try (Image image = Image.load("YOUR_DOCUMENT_DIRECTORY/img4.tif")) {
    ApngOptions op = new ApngOptions();
    op.setDefaultFrameTime(500); // Frame time set to 500 ms
    
    image.save(outputFilePath, op);
}
```

السطر `image.save(outputFilePath, op);` **يحفظ الصورة كـ APNG**. تأكد من أن اسم الملف النهائي ينتهي بـ `.png` وأن `ApngOptions` يعكس توقيت الإطارات المطلوب.

## كيفية حفظ الصورة كـ APNG في Java؟

استدعِ `image.save` مع كائن `ApngOptions` يحدد زمن الإطار الافتراضي. اضبط `setDefaultFrameTime` لتسريع أو إبطاء الرسوم المتحركة، ويمكنك إعادة استخدام نفس الاستدعاء لتنسيقات مصدر أخرى مثل PDFs متعددة الصفحات. يضمن استخدام كتلة `try‑with‑resources` تحرير موارد الصورة promptly، مما يمنع تسرب الذاكرة أثناء المعالجة الدفعية.
